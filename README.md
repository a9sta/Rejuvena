# 리쥬베나 (Rejuvena)

서울·인천·경기·부산 **동 1,232칸**과 지정 시군구 **152곳**으로 건너가는
출장마사지·홈타이 안내 사이트. 바깥 의존성 없이 Node 표준 라이브러리만 쓴다.

```
npm run regions   # /tmp/hjd.geojson → data/regions.json  (전국 맞닿음 그래프)
npm run build     # dist/ 생성
npm run check     # 빌드 결과 자체 검사 14종
npm run serve     # 로컬 미리보기
```

## 이 사이트가 세는 값 — 다리 수

전국 행정동 3,558곳의 경계를 모두 읽어 **꼭짓점을 둘 이상 나눠 가진 쌍**을 한 다리로
잇는다(꼭짓점 하나만 스친 쌍은 모서리만 닿은 것이라 세지 않는다). 그렇게 9,808개
다리가 생긴다. 그 그래프를 한 칸씩 건너가며

- **한 다리** 경계를 맞댄 칸 수
- **두 다리·세 다리** 한 칸씩 더 건너 닿는 칸의 누적 수
- **편심** 같은 시군구 안에서 가장 먼 칸까지의 다리 수
- **지름** 그 시군구 안 두 칸 사이의 최대 다리 수
- **길목** 이 칸을 빼면 시군구가 둘로 갈라지는가

를 낸다. 관리사는 그 동네에 상주하지 않고 가까운 칸에서 건너오므로, 몇 다리 안에
몇 칸이 붙어 있는지가 누가 올 수 있는지를 가른다.

★다리는 경계로 센 값이고 도로가 이어졌는지는 보지 않는다. 강이나 철길로 막혀
돌아가야 하는 쌍도 한 다리로 잡힌다. 소개 쪽에 그 한계를 적어 두었다.
★그래프를 **커버리지 안쪽만으로** 이으면 옆 시도로 넘어가는 다리가 끊겨 '두 다리
건너 몇 칸'이 거짓이 된다. 전국을 다 읽어야 한다. 메모리 때문에
`node --max-old-space-size=4096` 로 돌린다.

## 꼭 지키는 것

- **같은 주소 = 같은 HTML.** 무작위를 쓰지 않는다. 문장 고르기는 전부 md5 시드.
- **읍과 면은 쪽을 내지 않는다**(2026-10-13 지시). 시군구 쪽에 이름만 올린다.
- 전화번호는 `ringBtn()` 안에서만 찍힌다. 버튼 라벨은 '예약 문의' 하나.
- 후기·체험담·별점·인물 사진 없음. 푸터에 AI 활용 고지.
- 설명문은 100자 안쪽. FAQ 질문은 `h3` 질문형(순번은 h3 밖).
- `data/lastmod.json` 을 **반드시 커밋한다.**
